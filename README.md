# Simon Says Game

This project is a web-based implementation of the "Simon Says" game using HTML, CSS, and JavaScript. The game features a circle with different colored segments, and players must remember and reproduce a sequence of colors.

## Description

The goal of this project is to reinforce JavaScript skills by creating a functional and interactive game. The game follows the classic "Simon Says" rules:

1. The game shows a sequence of colors by lighting up the corresponding segments of the circle.
2. The player must then repeat the sequence by clicking on the segments in the correct order.
3. If the player successfully reproduces the sequence, the game continues to the next round with an additional color. Otherwise, the game ends.

## Features

- Interactive and visually appealing user interface.
- Randomly generated color sequences for each round.
- Progress tracking of the player's score and current round.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Usage

1. Clone this repository to your local machine.
`https://github.com/SpidySamurai/Simon_says.git`

2. Open the `index.html` file in your web browser.

3. Follow the instructions on the screen to play the game.
